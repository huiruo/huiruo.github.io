transform：转换

transform 的 5 种方法

transform 属性向元素应用 2D 或 3D 转换，可以对元素进行旋转、缩放、移动或倾斜：

  • translate()

  • rotate()

  • scale()

  • skew()

  • matrix()

  • translate() 方法 通过 translate() 方法，元素从其当前位置移动，根据给定的 left（x 坐标） 和 top（y 坐标） 位置参数：

css
/*值 translate(50px,100px) 把元素从左侧移动 50 像素，从顶端移动 100 像素。*/div{    transform: translate(50px,100px);}
  • 通过 rotate() 方法，元素顺时针旋转给定的角度。允许负值，元素将逆时针旋转。
css
/*值 rotate(30deg) 把元素顺时针旋转 30 度。*/div{    transform: rotate(30deg);}
  • 通过 scale() 方法，元素的尺寸会增加或减少，根据给定的宽度（X 轴）和高度（Y 轴）参数：
css
/*值 scale(2,4) 把宽度转换为原始尺寸的 2 倍，把高度转换为原始高度的 4 倍。*/div{    transform: scale(2,4);}
  • 通过 skew() 方法，元素翻转给定的角度，根据给定的水平线（X 轴）和垂直线（Y 轴）参数：
  • matrix() 方法把所有 2D 转换方法组合在一起。 matrix() 方法需要六个参数，包含数学函数，允许您：旋转、缩放、移动以及倾斜元素。

transform 和 translate 的区别

transform 是"大属性"，translate 是其中一个"小方法"

text
transform（变换）= 父属性    ├── translate()  → 移动位置    ├── rotate()     → 旋转角度    ├── scale()      → 缩放大小    ├── skew()       → 倾斜变形    └── matrix()     → 组合以上所有

类比理解：

类比CSS
运动 = transform变换（大属性）
跑步 = translate移动（一种变换方式）
转圈 = rotate旋转（一种变换方式）
变大变小 = scale缩放（一种变换方式）

写法：

css
/* transform 是属性名，translate 是方法名 */.box {  transform: translate(50px, 100px);  /* 移动 */  transform: rotate(30deg);           /* 旋转 */  transform: scale(2);                /* 缩放 */    /* 可以组合写 */  transform: translate(50px) rotate(30deg) scale(1.5);}

transform: translate(-50%, -50%)是什么意思？

这是水平垂直居中的经典写法

css
/* translate(x, y) 的参数 */transform: translate(-50%, -50%);/*         ↑        ↑        x轴偏移   y轴偏移        -50%表示相对元素自身宽度的一半（向左移动）        -50%表示相对元素自身高度的一半（向上移动）*/

配合 position 实现居中：

css
.parent {  position: relative;}
.child {  position: absolute;  top: 50%;              /* 定位到父元素中间（但元素左上角在中间） */  left: 50%;             /* 所以需要再往左上移动自身的一半 */  transform: translate(-50%, -50%);}

图解理解：

text
第一步：top: 50%; left: 50%┌─────────────────┐│                 ││       ┌──┐      │  ← 子元素左上角在中心点│       │子│ *    │     但整体偏右下│       └──┘      ││                 │└─────────────────┘        * 是父元素中心点
第二步：translate(-50%, -50%)┌─────────────────┐│                 ││       ┌──┐      ││     * │子│      │  ← 子元素中心点对齐父元素中心点│       └──┘      ││                 │└─────────────────┘        * 是父元素中心点，现在也是子元素中心点

⚠️ 注意：-50% 是相对于自身，不是父元素

css
/* 假设子元素宽度 100px，高度 80px */transform: translate(-50%, -50%);/* 等价于 */transform: translate(-50px, -40px);  /* 向左50px，向上40px */

方法1：translate():

元素从其当前位置移动，根据给定的 left（x 坐标） 和 top（y 坐标） 位置参数

css
/* 有两个div，它们的css样式如下： */.before {  width: 70px;  height: 70px;  background-color: #8fbc8f;}
.after {  width: 70px;  height: 70px;  background-color: #ffe4c4;  -webkit-transform: translate(50px, 30px);  -moz-transform: translate(50px, 30px);  -ms-transform: translate(50px, 30px);  -o-transform: translate(50px, 30px);  transform: translate(50px, 30px);}

方法2：rotate():

css
/* 元素顺时针旋转给定的角度。允许负值，元素将逆时针旋转。有两个div，它们的css样式如下 */.before {  width: 70px;  height: 70px;  background-color: #8fbc8f;}
.after {  width: 70px;  height: 70px;  background-color: #ffe4c4;  -webkit-transform: rotate(20deg);  -moz-transform: rotate(20deg);  -ms-transform: rotate(20deg);  -o-transform: rotate(20deg);  transform: rotate(20deg);}

方法3.scale()

元素的尺寸会增加或减少，根据给定的宽度（X 轴）和高度（Y 轴）参数

css
.before {  width: 70px;  height: 70px;  background-color: #8fbc8f;}
.after {  width: 70px;  height: 70px;  background-color: #ffe4c4;  -webkit-transform: scale(1.5, 0.8);  /*宽度变为原来的1.5倍，高度变为原来的0.8倍*/  -moz-transform: scale(1.5, 0.8);  -ms-transform: scale(1.5, 0.8);  -o-transform: scale(1.5, 0.8);  transform: scale(1.5, 0.8);}

方法4.skew()

元素翻转给定的角度，根据给定的水平线（X 轴）和垂直线（Y 轴）参数

css
.before {  width: 70px;  height: 70px;  background-color: #8fbc8f;}
.after {  width: 70px;  height: 70px;  background-color: #ffe4c4;  -webkit-transform: skew(20deg, 20deg);  /*围绕 X 轴把元素翻转20度，围绕 Y 轴翻转20度*/  -moz-transform: skew(20deg, 20deg);  -ms-transform: skew(20deg, 20deg);  -o-transform: skew(20deg, 20deg);  transform: skew(20deg, 20deg);}

动画-animation-transition

transition 和 animation 的区别

transition（过渡）= "被动"变化

需要触发条件（如 hover、click），从状态A变化到状态B。

css
/* transition：鼠标悬停时，宽度从100px变成200px */.box {  width: 100px;  transition: width 1s;  /* 宽度变化需要1秒 */}
.box:hover {  width: 200px;  /* 悬停触发变化 */}

animation（动画）= "主动"播放

自动播放，可以设置多个关键帧（0%、25%、50%、100%），循环播放。

css
/* animation：自动循环播放，不需要触发 */.box {  animation: myAnim 2s infinite;  /* 无限循环播放 */}
@keyframes myAnim {  0%   { width: 100px; }   /* 开始状态 */  50%  { width: 200px; }   /* 中间状态 */  100% { width: 100px; }   /* 结束状态 */}

对比：

特点transitionanimation
触发方式需要事件触发（hover等）自动播放
状态数量只有两个状态（开始→结束）可以有多个关键帧
循环播放不能循环，一次性可以循环（infinite）
控制精细度简单，只能控制时长精细，可以控制每一帧

transition 常用写法

css
/* 完整写法 */transition: property duration timing-function delay;
/* 示例 */transition: width 1s ease 0.5s;/*         ↑     ↑    ↑     ↑         属性  时长  缓动  延迟         要变化 原理用什么函数 开始前等多久 */
/* 常用简写 */transition: width 1s;        /* 只写属性和时长 */transition: all 0.3s;        /* 所有属性都用0.3s过渡 */transition: width 1s, height 2s;  /* 多个属性分别设置 */

timing-function 缓动函数：

值效果
linear匀速，从头到尾速度一样
ease慢→快→慢（默认，最自然）
ease-in慢→快（开始慢）
ease-out快→慢（结束慢）

animation 常用写法

css
/* 完整写法 */animation: name duration timing-function delay iteration-count direction;
/* 示例 */animation: myAnim 2s ease 0s infinite alternate;/*         ↑      ↑   ↑    ↑     ↑        ↑         名称  时长 缓动 延迟  播放次数  方向 */
/* 常用简写 */animation: myAnim 2s;           /* 只写名称和时长 */animation: myAnim 2s infinite;  /* 无限循环 */animation: myAnim 2s 3;         /* 播放3次 */

关键帧 @keyframes：

css
@keyframes myAnim {  /* 方式1：用百分比控制每一帧 */  0%   { transform: scale(1); }  50%  { transform: scale(1.5); }  100% { transform: scale(1); }    /* 方式2：用 from/to（等价于 0%/100%） */  from { opacity: 0; }  to   { opacity: 1; }}
