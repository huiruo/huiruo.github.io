Vue transition 过渡动画原理

一句话总结：Vue 自动给元素添加/移除 6 个 CSS 类，配合 CSS transition 实现动画。

核心原理：

  1. 元素进入/离开时，Vue 自动添加对应 CSS 类名（如 fade-enter、fade-leave）
  2. CSS 类名触发 transition 过渡效果
  3. 动画结束后，Vue 自动移除所有类名，恢复元素正常状态

简化写法（记住这个就够了）：

css
.fade-enter-active, .fade-leave-active { transition: opacity 0.5s; }.fade-enter, .fade-leave-to { opacity: 0; }

代码示例

核心：Vue 自动添加/移除 6 个 CSS 类

当元素被 <transition> 包裹后，Vue 会自动在动画过程中添加和移除 CSS 类：

text
进入动画（Enter）：┌──────────────────────────────────────────────┐│  开始帧                                       ││  添加：fade-enter + fade-enter-active         ││  ↓                                            ││  第二帧                                       ││  移除：fade-enter                             ││  添加：fade-enter-to                          ││  ↓                                            ││  动画结束                                     ││  移除：fade-enter-active + fade-enter-to      ││  元素恢复正常状态                              │└──────────────────────────────────────────────┘
离开动画（Leave）：┌──────────────────────────────────────────────┐│  开始帧                                       ││  添加：fade-leave + fade-leave-active         ││  ↓                                            ││  第二帧                                       ││  移除：fade-leave                             ││  添加：fade-leave-to                          ││  ↓                                            ││  动画结束                                     ││  移除：fade-leave-active + fade-leave-to      ││  元素从 DOM 中移除                            │└──────────────────────────────────────────────┘

6 个类的作用

类名作用何时存在
fade-enter进入的初始状态（动画开始前的样式）只在第一帧
fade-enter-active进入的过渡过程（定义 transition 属性）整个动画期间
fade-enter-to进入的结束状态（动画结束后的样式）第二帧到结束
fade-leave离开的初始状态只在第一帧
fade-leave-active离开的过渡过程整个动画期间
fade-leave-to离开的结束状态第二帧到结束

实际例子：淡入淡出动画

css
/* 进入动画 */.fade-enter {  opacity: 0;              /* 开始时透明 */}.fade-enter-active {  transition: opacity 0.5s; /* 定义过渡时间 */}.fade-enter-to {  opacity: 1;              /* 结束时可见（可不写，默认就是1） */}
/* 离开动画 */.fade-leave {  opacity: 1;              /* 开始时可见（可不写，默认就是1） */}.fade-leave-active {  transition: opacity 0.5s; /* 定义过渡时间 */}.fade-leave-to {  opacity: 0;              /* 结束时透明 */}
/* 简化写法（常用） */.fade-enter-active, .fade-leave-active {  transition: opacity 0.5s;}.fade-enter, .fade-leave-to {  opacity: 0;}

Vue 模板写法

html
<transition name="fade">  <p v-if="show">hello</p></transition>
<!-- name="fade" 对应 CSS 类名前缀 fade-enter、fade-leave 等 --><!-- 如果不写 name，默认前缀是 v，即 v-enter、v-leave -->

动画过程详解

以进入动画为例：

text
第一帧：  元素 class: "fade-enter fade-enter-active"  opacity = 0（透明状态）
第二帧：  Vue 移除 fade-enter  元素 class: "fade-enter-active fade-enter-to"    此时 opacity 从 0 → 1 变化  fade-enter-active 监听到变化，开始 0.5s 过渡
动画期间：  元素逐渐从透明变成可见
最后一帧：  Vue 移除 fade-enter-active 和 fade-enter-to  元素恢复正常，opacity = 1

过渡模式（mode）

当两个元素切换时，可能会出现同时存在的情况。用 mode 属性控制切换顺序：

三种模式

模式效果适用场景
in-out新元素先进入，旧元素再离开默认，一般不用
out-in旧元素先离开，新元素再进入常用，切换更自然
无 mode新旧元素同时过渡可能重叠，不推荐

图解理解

text
无 mode（默认）：旧元素离开 ←←←←←←←←←←←←←←←←←                        ↑ 此时两个元素同时存在，可能重叠新元素进入 →→→→→→→→→→→→→→→→→
out-in 模式：旧元素离开 ←←←←←←←←←←←←←←←←←                        ↓ 等旧元素完全离开后                        ↓新元素进入 →→→→→→→→→→→→→→→→→

代码示例

html
<!-- out-in：先离开再进入（推荐） --><transition name="fade" mode="out-in">  <div v-if="show" key="a">元素 A</div>  <div v-else key="b">元素 B</div></transition>
<!-- 注意：切换的两个元素必须有不同的 key -->
