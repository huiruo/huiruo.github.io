构建对比记录

2月2日构建（成功）✅

  1. Cloudflare Pages clone 代码 (commit 21bba1b)
  2. 读取 pnpm-lock.yaml → ⚠️ WARN: Ignoring not compatible lockfile
  3. 重新解析 package.json 的 "pixi.js": "^8.9.1"
  4. pnpm 查询 npm registry → 当时最新版本是 8.15.0
  5. 安装 pixi.js@8.15.0
  6. Next.js build → pixi.js 8.15.0 兼容 SSR ✅
  7. 部署成功

2月4日构建（失败）❌

  1. Cloudflare Pages clone 代码 (commit 251b142)
  2. 读取 pnpm-lock.yaml → ⚠️ WARN: Ignoring not compatible lockfile
  3. 重新解析 package.json 的 "pixi.js": "^8.9.1"
  4. pnpm 查询 npm registry → 🆕 新版本 8.16.0 刚发布！
  5. 安装 pixi.js@8.16.0
  6. Next.js build → pixi.js 8.16.0 在 SSR 时访问 navigator ❌
  7. [ReferenceError: navigator is not defined]

🔍 技术细节

1. Lockfile 不兼容

bash
# 你的本地环境pnpm 8.11.0 → 生成 lockfileVersion: '6.0'
# Cloudflare Pages 环境pnpm 10.11.1 → 需要 lockfileVersion: '9.0'
# 结果⚠️ Ignoring not compatible lockfile→ 每次构建都重新解析依赖版本
